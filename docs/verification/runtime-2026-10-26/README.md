# Local verification evidence - 2026-10-26

Application/test source under test: `c07b1ad`. Subsequent presentation commits change documentation/evidence only. Java 21, Maven 3.9.16, Docker Desktop Linux engine and PostgreSQL 17.6 ran locally on Windows; hardware and Docker memory limits are in regression.json.

- [Regression](regression.json): `mvn -B -ntp package`, exit 0; 369 selected, 368 passed, no failures/errors, one intentionally skipped opt-in benchmark. All 49 suites are listed. Includes executable JAR SHA-256 and observed corrections.
- [Golden report](eval-report.md) and [JSON](eval-report.json): 12/12 synthetic cases. Version checks are included; this is objective fake-provider regression evidence, not a real-model quality benchmark.
- [Live demos](live-demos.json): one API JVM and two independent worker JVMs against Compose PostgreSQL. DAG completion, compensated Saga, completed retrieval, exact bound refund approval and bounded runaway termination passed. Aggregate provider effects and worker ownership outcomes are in the adjacent text files. One failed task is the intentional Saga shipment; compensation completed.
- [Benchmark invocations](benchmarks.json): seven separate opt-in test runs, all exit 0 and valid with zero errors. Queue 1/4/16 consumer threads each processed 100 workflows; start/DAG/timer/signal used 20. Start intentionally does not advance workflows. Reports preserve measured samples but are cold exploratory smoke runs with no warmup/repetition, not production or multi-host scaling evidence.
- [Queue plan](queue-plan-local.txt): actual EXPLAIN (ANALYZE, BUFFERS) of the documented claim query in BEGIN/ROLLBACK against the small retained demo database, with no eligible work remaining. This validates query execution only; its empty-result plan is not a representative loaded-queue performance study.
- [Raw evidence hashes](raw-evidence-hashes.json): SHA-256 of local ignored logs and the preserved Surefire archive. Raw XML/logs stay in target because JVM environment and exception output need not be published. Full-suite reports were preserved before benchmark invocations could overwrite the benchmark report.

Every verification/API/worker JVM used `JAVA_TOOL_OPTIONS=-Duser.timezone=UTC` to avoid the host's rejected legacy Asia/Calcutta timezone name. DEBUG was set false for the clean full run and benchmarks. Portable tools remain outside the repository; execution policy and machine-wide PATH were not changed. Testcontainers used disposable databases, while the live Compose volume was retained. Temporary API/worker processes were stopped after evidence collection; that cleanup is not a crash-recovery experiment.

Deferred: actual OS-kill/network-partition/DB-restore drills, warmed repeated or sustained HTTP/multi-host load, real provider adapters, production authentication and reviewer authorization, HA/PITR operations and other boundaries on the [verification board](../../runtime-verification-progress.md).
